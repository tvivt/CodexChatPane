## 1. 启动

开发环境在项目根目录执行：

```powershell
npm ci
npm run tauri dev
```

发布版直接运行 `CodexChatPane.exe`，无需安装；目标 Windows 需要已安装 WebView2 Runtime。

CodexChatPane 启动后先读取目录元数据并展示列表，后台再补工作状态和项目路径可用性；尚未同步的状态显示中性 `·`。它不会创建新的 Codex 账户，也不会把数据上传到远端。

如果只执行 `npm run dev`，得到的是浏览器前端预览：可以查看布局和部分交互，但不能读取本机 Codex 数据、联动窗口或执行 Codex 操作。

## 2. 主界面

从 v0.5.1 起只显示 Projects 页的内容，顶部隐藏 Projects/Chats 标签切换。独立 Chats 页暂时保留代码，但不提供入口。标题栏的 CodexChatPane 加粗，旁边显示从包版本读取的版本号。

额度百分比后以相同文字颜色显示 `|` 和可用重置卡数量；可用卡最近到期时间在 7 天内显示 ⚠、3 天内显示 ❗，标识紧接数字。悬停额度区域统一显示额度重置时间、卡数量与各批到期时间；数量未知时显示 `—`。

### Projects

Projects 区域用于从 Project 角度查看最近对话：

- 顶部动态区域列出最近 N 天的对话；“动态规则”按钮汇总手动加入或移出的对话。
- Project 结构区域显示 Codex Project 和本地 Folder。
- 选择 Project 后，右侧或下方区域显示该 Project 的 Chat。
- 没有 Project 的对话会进入固定的“无项目对话”合成项目，不会被伪造为真实 Project。

Projects 页面只在 Projects 标题栏保留关闭按钮，同时收起 Projects 与 Chats。收起后只保留两栏名称和 Projects 的向上展开图标，工具图标、数量、文件夹与列表全部隐藏；Chats 的归档面板一并隐藏。点击 Projects 的向上展开图标同时恢复两栏，保留原有文件夹展开状态、高度和归档开关。旧配置中两栏的独立收起状态以 Projects 为准。

### Chats

以下是保留的独立 Chats 页能力，当前源码主界面不显示该页。

Chats 区域用于全局浏览和整理对话：

- `PIN` 显示 Codex 中已 Pin 的对话。
- `ALL` 显示可用对话。
- 自建 Folder 可以多级嵌套；一个 Chat 可以被整理到本地 Folder。
- 支持搜索、Project 过滤、排序、归档视图和多选。
- 对话状态顺序为：待回答、已完成待查看、工作中、已读。有有效的结构化提问时，Chat 行显示与 Project 相同的 `?`，悬停提示“待回答”；弹窗回答只清对应问题，普通用户消息使此前等待失效，然后恢复实际执行/已读状态。普通正文里的问句不触发此状态。异步提问不会仅因本轮完成而自动清除；历史回放和缓存合并也遵循相同的失效规则。

动态列表的 P 控件按项目“关闭 → 升序 → 降序 → 关闭”循环，N 控件按“工作状态 → 名称升序 → 名称降序 → 工作状态”循环；同一控件一次只有一个方向。P 开启时先分项目，再按 N 的选择排项目内对话；状态排序没有反向状态模式。文件夹结构中的名称排序按“活动顺序 → 升序 → 降序”循环，独立于动态列表。项目过滤支持多选和搜索；清除表示不限制。最近天数与手动加入/移出共同决定动态候选，搜索再过滤当前候选。

Folder 的箭头只改变展开状态，文件夹图标表示实体；标题栏还支持全部展开/折叠、拖动分栏高度与列宽。Ctrl/Meta 多选，Shift 选择当前列表范围；批量移动只在目标关系有效时可用。自动归类和合成项目不能作为真实目录管理。

## 3. 常用操作

### 打开对话

点击 Chat 行或操作菜单即可让 Codex Desktop 打开对应对话。CodexChatPane 不复制对话正文，只通过 Deep Link 定位目标。

### 预览对话

对话预览默认关闭。在设置中开启后，Chat 行才显示预览入口。内容按需从对应 rollout 分页读取；关闭预览后不会把正文保存到工具配置。

若要覆盖最近天数过滤，右键对话选择“动态显示 → 自动、加入、移出”。“动态规则”对话框列出两组覆盖，也能把对话恢复为“自动”。

### 查看对话统计

详情页轮次表中，开启 Fast 的轮次会在模型信息后显示 `· Fast`，普通或配置未知的轮次不加标识。标识取该轮开始时已记录的服务档位配置，不用当前配置回填历史，也不代表服务端确认的实际处理档位。

点击对话时，状态栏只读取当前选中对话的当前轮次，采用最近一次有效、已结算的模型请求，包括中断轮次。额度左侧显示 `1.8s·62t/s·93%`：首 token、含推理的估算生成速度、输入缓存命中率；不对当前轮次全部请求求平均。首 token 必须对应这次请求：仅首个请求可使用整轮原生值或可靠起点的估算，后续请求缺少可靠首字边界时显示 `—`。时间优先保留，窄窗口中指标可截断，tips 显示状态、首 token、速度、覆盖率和缓存命中率。点击指标，或选择普通对话右键菜单最后一项“对话详情”，打开独立、可缩放的无系统标题栏窗口；内部标题区可拖动，并提供最小化、最大化和关闭按钮。

只有打开详情时才读取目标历史；默认展示当前轮次汇总，轮次列表倒序、每页最多 50 条，可切换当前页其他轮次或全会话已完成轮汇总。统计卡片包含随范围变化的活动记录数；请求明细和活动明细已移除。翻页复用同一截至时刻的摘要快照，局部更新，不重读日志；重新打开或刷新才检查新版本。父页只列直接子代理身份/模型，点击才读取其自身统计，不递归读整棵树。状态栏不读取子代理文件，也不混入继承历史用量。速度排除工具等待，计时不可靠的请求暂不采用；新请求结算和轮次终止后自动更新状态栏与 tips。同轮没有新有效样本时保留此前有效请求，新轮没有样本显示 `—`。状态栏明文追加增量读取，未变化复用；详情冷读或版本变化后仍可能完整解析目标文件。归档右键仍只有“恢复对话”。

详情中的“本对话消耗”单独统计自身全部已结算请求，包括中断和进行中轮次，显示 Token、API 等价金额和价表日期；它不随上方轮次选择改变范围，也不包含子代理。费用未知与计时缺失分别处理，不能把没有速度的有效用量丢掉。

本机按用户规则把 gpt-reserve、codex-auto-review、gpt-5.3-codex-spark 及缺模型名称的请求金额记 0，保留 Token 和请求数，不触发“＋未计价”；其他未知价仍保留未计价。这不是服务端免费承诺。

Σ 始终位于额度左侧，Σ 后不留空格。有预测时如 `Σ≈125t/s`；没有参与统计的对话时为 `Σ0t/s`；有运行中对话但全部缺少有效样本时为 `Σ—`。悬停左列显示 `对话名[模型]`，右列显示 `Xt/s` 并右对齐，tips 不带约等号；刷新保留 Σ 悬浮节点，未知为 `—`；部分可估算时注明“2/3 个运行中对话”。每个主对话取最近至多 3 次同配置有效请求按耗时加权，再把各运行中对话的预测相加。工具执行、等待返回和长推理静默期间保留预测，不按沉默时间淘汰；有可靠证据表明当前正在压缩时排除，压缩结束仍运行则恢复。完成、中断、失败、空闲、待回答及子代理不参与。它是运行中对话的估算生成能力之和，不是每秒实际收到的 Token，不改变选中对话单次指标，也不预测首字。

额度显示为 `5h 圈 百分比 HH:mm W 圈 百分比 | 卡数量`；没有 5h 时只显示周额度圆环与百分比，不显示 W。卡数量取服务端剩余可用数量，0 也显示，未返回时显示 `—`。有已知且未到期的可用卡在 7 天内到期，数量后显示 `⚠`；3 天内显示优先级更高的 `❗`，包含临界值，未知到期时间不猜测，0 卡不警告。只有 5h 在状态栏显示重置时间；整块额度共用一个 tips，汇总两种额度、完整重置日期时间、倒计时和各批卡的到期信息。倒计时超过 24 小时用天和整小时，例如 `(-1d2h)`；24 小时及以内保留小时和分钟。点击数量或标识也打开同一个额度详情窗口。

点击额度打开独立“额度与消耗”窗口，默认“重置记录”：当前 W 置顶＋最近 5 条历史，每次更多追加 10 条。消耗页初选当前 W，可在 W 周期与自然时间（日/周/月/全部）之间互斥切换；周期文字立即单选，勾选框多选后应用，每行含周期长度，不显示重置方式。项目、来源及 Fast 组合筛选，按项目、日期或对话汇总。模型通过顶部合计表、每日堆叠趋势和展开子行拆分；趋势默认 Token，可切 API 等价金额。对话行可看问题轮次与子代理构成，API 金额是本地估值。额度 tips 显示重置卡数量与到期时间。提前重置通知保留到手动关闭，含周期、剩余额度、各模型 Token/占比和 API 等价。详细口径见[额度与消耗记录](usage-history.zh-CN.md)。

额度窗口变化不等于重置。固定/浮动模式需连续观察；只有截止时间变化时保留内部候选，首次消费不会移动已有周期起点。周期标签、时长、筛选和消费统一使用同一 `[start,end)` 边界，历史补证据后关闭状态仍保留；缺少观察的重置不会补造。

### 整理 Folder

在 Projects 或 Chats 区域创建本地 Folder，然后把 Project 或 Chat 拖入目标位置。Folder、Group、顺序和折叠状态属于 CodexChatPane，不会写回 Codex 的 Project 结构。

### 使用 Group

Group 是本地的交叉组织方式。一个 Project 或 Chat 可以属于多个 Group；删除 Group 只删除本地关系，不删除 Codex 数据。

组工具栏支持新建、重命名、删除（包含子组关系），组标题可拖动排序。项目/对话从普通组拖到另一组时迁移当前组关系，其他组关系保留；拖回 ALL 清除自定义组关系。从固定 Pin/Star 组拖出是复制关系，不取消 Pin/Star。组数据共享成员关系，但每个视图保留自己的组顺序、组内顺序和折叠状态。Project 可有多个本地 Folder 归属，Chat 的本地 Folder 属于它的 Project。

### 修改 Codex 状态

重命名、Pin、归档和 Project Pin 属于 Codex 写操作：

1. 在设置中启用“Codex MCP 操作”。
2. 首次执行时确认授权。
3. 从 Chat 或 Project 菜单执行操作。
4. 等待操作完成；发生错误或报警时会显示常驻通知。

从右键菜单归档对话；归档对话在标题前保留恢复图标。归档和恢复均直接执行，不再二次确认。已归档 Chat 通常需要先恢复后才能继续重命名或 Pin。

## 4. 设置

设置页提供：

- 中文/英文。
- 亮色/暗色和主题族。
- 主题族包括 Catppuccin、Tokyo、Gruvbox、Everforest、Ayu；Tab/栏/行字号独立设置，范围 8–20，步长 0.5。
- Tab、栏和行字号。
- 普通窗口、随 Codex 显示、全局置顶。
- 日期颜色竖条。
- 对话预览开关（默认关闭）。
- 日志级别。
- Codex MCP 操作开关。
- 工具配置导入和导出。

本地设置位于 `%CODEX_HOME%\.codex-chat-pane\settings.toml`，Folder、Group、Star 和动态规则位于同目录的 `folders.json`。未设置 `CODEX_HOME` 时，根目录为 `%USERPROFILE%\.codex`。这些文件由应用生成，不进入仓库。

窗口位置保存为物理像素 X/Y，宽高按逻辑尺寸恢复，支持双屏负坐标和不同 DPI；保存位置必须与至少一块当前显示器相交，断开显示器时不强制恢复到屏幕外。最大化时不覆盖正常窗口几何，独立详情/预览不保存主窗口尺寸。旧 `windowPinned` 迁移到窗口模式，旧 localStorage 前缀兼容读取后迁移。配置导入先校验版本、字段和数值，失败不替换现有配置；导出只包含工具设置和整理关系，不导出对话正文、登录数据或统计数据库。

“随 Codex 显示”通过 Windows 窗口事件管理显隐和所属窗口；“普通窗口”和“全局置顶”分别使用普通窗口与系统置顶。托盘可恢复、隐藏、退出；主窗口关闭和独立窗口关闭互不混淆。诊断页的远程调试端口默认 0，修改后需完全重启；它是可选开发入口，Σ 不使用 WebView 注入或调试协议。

## 5. 常见问题

### 页面显示“正在读取 Codex 数据”或同步失败

确认 Codex Desktop 正在运行，并检查 Codex 数据目录是否可访问。可通过 `CODEX_HOME` 指向自定义数据目录。应用会保留最后一次有效快照，不会用空列表覆盖已有内容。

### 只能浏览，不能重命名或归档

只读浏览不依赖 MCP。写操作需要在设置中启用 Codex MCP；Codex 更新后内部 MCP 可能发生变化，此时写操作会失败，但不会影响本地 Folder 整理。

### 想重置本地界面状态

先关闭应用，再备份并移走 `%CODEX_HOME%\.codex-chat-pane\` 下的 `settings.toml` 和 `folders.json`。下次启动时会使用默认设置并重新创建本地配置。

### 想查看调试信息

在设置中将日志级别调为 `debug`。App 日志位于 `%CODEX_HOME%\.codex-chat-pane\logs\window-attach.log`，不提交到仓库；文件名沿用早期窗口联动实现，内容也包含源刷新、MCP 和内部测试事件处理信息。

## 6. 右键菜单速查

菜单随目标和有效能力变化；禁用项保留不可用原因。Star、Pin 在行按钮操作，Group 的创建/改名/删除在组控件操作。

| 目标 | 当前菜单行为 |
| --- | --- |
| 普通 Chat | 动态显示（自动/加入/移出）、重命名对话、归档对话、移动对话、所属项目、打开文件夹、复制标题/链接；有诊断时可复制诊断；最后为对话详情 |
| 已归档 Chat | 仅恢复对话；需要已启用 MCP |
| 多选 Chat | 动态覆盖和批量移动；移动要求同项目及可用目标，不批量改名/归档/打开详情 |
| 普通 Project | 在 Codex 新建对话、移动到本地项目文件夹、打开目录、复制名称/路径/ID；合成项目只支持适用项，如新建无项目对话 |
| 多选 Project | 移动到本地项目文件夹；单目标动作省略 |
| Group 标题 / 动态区空白 | 当前组展开/收拢；空白处全部展开/折叠 |
| 自建 Folder | 展开/收拢、新建子文件夹、重命名、移动嵌套、删除；自动文件夹只可展开/收拢 |
| Folder 区空白 | 新建文件夹、全部展开/折叠 |
| Timeline 空白 | 全部展开/折叠、包含归档、关闭 Timeline |
| 选中对话状态栏 | 复制发送时间、执行时间或完整时间信息 |
| 额度状态栏 | 复制额度及重置时间 |
| 标题栏 / 状态栏空白 | 导出/导入工具配置 |

本地 Folder 删除/回收与 Codex 归档不同：前者改变整理关系和本地回收视图，后者通过 MCP 改 Codex 状态。移动嵌套会拒绝把文件夹放入自身或后代；不会删除项目目录或原始 rollout。

所有右键菜单在点击菜单外、应用失去焦点（包括点击其他应用）或按 Esc 时关闭。归档菜单使用独立目标，只显示“恢复对话”，不透过归档面板命中下方普通行；归档面板不做透明处理。
