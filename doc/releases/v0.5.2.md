# v0.5.2

2026-10-29 · Windows portable release

## 中文

- Projects 和 Chats 各自关闭、各自展开，互不影响。分别保存收起状态，保留文件夹展开状态和栏高。
- Chats 收起时隐藏其归档面板，恢复后按原归档开关显示；只关闭 Projects 不影响 Chats 和归档面板。
- 移除 Projects/Chats 标题前的批量折叠/展开箭头。文件夹自身的箭头、各栏恢复按钮和右键菜单中的“全部展开/折叠”保留。
- 修复 v0.5.1 Windows CI 的进程退出测试：正常返回后的 PowerShell 退出等待从测试专用的 200ms 改为程序实际使用的 2 秒，并加入 300ms 延迟退出回归场景。保留无响应、退出卡住、重试及进程树清理检查；不改变程序的查询和退出超时。
- 更新版本字段、中英文首页、使用说明、产品文档和发布说明。

## English

- Give Projects and Chats independent close and restore controls. Preserve each section's collapse state, folder expansion and saved height.
- Hide the archive panel while Chats is collapsed and restore it according to its saved switch. Closing Projects leaves Chats and its archive panel visible.
- Remove the bulk expand/collapse arrows before section titles. Keep folder-row arrows, section restore buttons and the background menu's expand/collapse-all actions.
- Fix the Windows CI process-exit test that failed in v0.5.1. Use the production two-second exit grace instead of a test-only 200ms limit, and cover a normal process with a 300ms delayed exit. Retain stalled-query, stalled-exit, retry and process-tree cleanup assertions; production timeouts are unchanged.
- Update version fields and both language guides.
