# v0.5.5

## 中文

- 回答刚开始时，单对话速度使用该对话最近最多 3 次有效请求估算。样本须匹配当前模型、推理强度和服务档位。首次打开面板也会读取近期样本，悬停可查看速度来源。
- 本轮首笔有效请求结算后，单对话速度切换为本轮最新有效请求的速度。如果没有匹配的历史样本，首笔结算前显示 `—`。
- 修复了运行中速度总和（Σ）漏计对话的问题。面板现在会读取轮次开始前已生效的服务档位，使匹配的速度样本正常计入总和。

## English

- At the start of a reply, the selected chat estimates its speed from up to three recent valid requests in the same chat. Samples must match the current model, reasoning effort, and service tier. The estimate also works when the pane is first opened. Hover over the speed to see its source.
- Once the first valid request settles, the selected chat shows the speed of the latest valid request in that turn. If no matching history is available, the pane shows `—` until the first valid request settles.
- Fixed a case where the running speed total (Σ) omitted a chat. The pane now reads the service tier already in effect when the turn started and includes matching samples in the total.
