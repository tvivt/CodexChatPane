# v0.5.0

2026-10-29 · Windows portable release

## 中文

### 额度与消耗

- 修复旧日志缺少账号归属、来源字段缺失和空闲时重置时间漂移导致的错误周期。重新推导周期，保留原始观察与通知关闭记录；无法确认账号的历史不强行归入当前账号。
- 点击额度默认打开重置记录，当前周期置顶，初始显示 5 条历史，每次加载更多 10 条。周期选择每行一个周期，显示周期长度，省略“提前重置”字样。
- 消耗页支持周期多选、自然时间、项目/来源/Fast 筛选、模型拆分和每日趋势；总 Token 按输入加输出统计，缓存和推理不重复相加。
- 本地 API 等价金额将 `gpt-reserve`、`codex-auto-review`、`gpt-5.3-codex-spark` 和未提供模型名的有效请求按 0 处理。请求数和 Token 仍保留；这是本工具的估值规则，不代表官方免费或实际账单。

### 对话详情与性能

- 对话详情默认最新轮次，历史每页 50 轮，页面切换复用紧凑摘要，减少大日志的传输与渲染。
- 概览新增活动记录数；移除请求明细、活动明细正文列表，保留轮次摘要、工具汇总、消耗和子代理入口。
- 目录元数据先显示，活动后台补齐；日志分析采用可失效的检查点和账号/来源隔离缓存。

### 界面

- 修复速度总和 tips 刷新闪烁。每行以“对话名[模型]”左对齐、速度右对齐，tips 不带约等号，模型显示省略 `gpt-` 前缀。
- 仅保留 Projects 的关闭/展开按钮，同时控制 Projects 与 Chats；恢复时保留栏高、文件夹展开状态和归档开关。
- 右键菜单统一使用“移动对话”；待回答状态统一显示 `?`，并完善等待状态解析和归档恢复。
- 同步中英文首页、使用说明、产品模型、架构、接入、开发说明与统计专题，新增全功能文档索引。

## English

- Fix quota-cycle reconstruction across missing account/source metadata and drifting idle reset deadlines. Keep raw observations and dismissed notices; unattributed history is not assigned to the current account.
- Open quota history by default: current period plus five ended periods, ten more per load. Period options show duration on one line.
- Add model breakdowns, daily trends, period/calendar ranges and usage filters. Total tokens are input plus output, without counting cached input or reasoning twice.
- Apply the local zero-cost policy to valid requests for `gpt-reserve`, `codex-auto-review`, `gpt-5.3-codex-spark`, and missing model names. Preserve request/token counts; estimates are not an official bill or a claim of free service.
- Page chat details in batches of 50 turns using compact summaries. Add activity counts and remove request/activity body lists while retaining tools, usage and subagent navigation.
- Render catalog metadata before deferred activity and reuse invalidatable log checkpoints and account/source-scoped caches.
- Stabilize aggregate-speed tooltips and show left-aligned chat/model names with right-aligned speeds. Omit the `gpt-` display prefix.
- Control both Projects and Chats from the Projects close/restore button. Rename the context-menu item to “Move chat”. Improve awaiting-answer status and archive restoration.
- Refresh both language guides and technical references, with a complete documentation index.

Requires Windows, Codex Desktop and WebView2 Runtime. The executable is unsigned. Local data formats and internal Codex MCP may change between Codex versions.

需要 Windows、Codex Desktop 和 WebView2 Runtime；程序未签名。Codex 本地格式与内部 MCP 可能随版本变化。旧记录缺少账号、请求计时或模型信息时，相关统计仍可能不完整。默认测试不包含所有真实账号切换、原生界面交互及全历史性能组合。
