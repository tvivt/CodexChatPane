# v0.6.0

## 中文

- 项目过滤默认全部勾选，点击单项取消选择；全选恢复全部项目，清除取消全部项目。区分全部选择与全不选的保存状态，兼容原有配置。

- 子智能体列表按明确的直接父子关系归属，排除父代理、同级代理和其他交互对象；没有直接子代理时隐藏整个子智能体区域。
- 主对话详情先显示，再逐个后台回填子代理统计。汇总表包含名称、模型、状态、输入 token、输出 token、缓存命中率、估算速度和 API 等价金额；窄栏隐藏模型与缓存列，模型可悬停查看。
- 点击子代理打开完整的正常对话详情，包含轮次、请求、工具和用量统计，并可继续查看它直接创建的子代理。
- 汇总用量包含自身全部已结算请求，保留进行中和中断轮次的有效用量；速度采用有效计时样本并排除工具等待。速度提示显示覆盖率，加载中显示省略号，失败显示原因。统计排除继承历史和其他代理用量。
- 普通和归档对话右键菜单新增“对话预览”，可在行内预览图标关闭时直接使用。

## English

- Project filtering initially checks all projects. Click a project to deselect it, use Select all to restore all projects, or Clear to deselect all. Saved all/none states are distinct, with migration for existing settings.

- Subagent lists use explicit direct-parent relationships, excluding parents, peers and other interaction targets. Chats without direct children omit the section.
- Parent details render first, then fill child summaries sequentially in the background. The table shows name, model, status, input/output tokens, cache hit rate, speed and API-equivalent cost. Narrow panes hide model and cache columns; the model remains in the name tooltip.
- Clicking a subagent opens normal full chat details, including turns, requests, tools and consumption, with navigation to its own direct children.
- Summary usage includes all own settled requests, including active and interrupted turns. Speed uses valid timed samples and excludes tool waits, with coverage in the tooltip. Pending rows show an ellipsis and failures show the reason. Inherited history and other agents' usage are excluded.
- Active and archived chat context menus now offer Chat preview, including when row preview icons are disabled.
