# v0.6.7

## 中文

- 程序名悬停提示显示实际版本，顶栏不再常显版本号。新增本次运行内的前进/后退历史：只记录从 Pane 成功打开的对话，连续相同目标去重，支持返回后开新分支，失败保留历史位置。既有普通点击、右键打开及联动开关行为保留；箭头导航才主动选中目标。
- 对话标题提示增加 `[对话 ID 末四位]` 前缀，覆盖项目列表、最近动态、时间线及运行列表；可见标题不变。缓存命中率以百分比显示到小数点后两位，并调整主题样式。

## English

- The running version is shown in the app-name tooltip. Session-only back/forward history records successful opens from Pane, deduplicates consecutive targets, supports branching and preserves position on failure. Existing click, context-menu and linkage behavior is preserved; arrow navigation selects its target.
- Chat-title tooltips start with the final four characters of the actual conversation ID; visible titles remain unchanged. Cache hit rates show two decimal places, with theme style updates.
