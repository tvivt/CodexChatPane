# v0.6.3

## 中文

- 打开预览时一次读取所选对话，以用户完整提问生成可展开的大纲。长标题自动换行，收到新消息时保留展开状态和阅读位置。
- 展开后，图片按上传顺序显示在用户正文前，可点击放大。文件附件可点击打开，工具记录显示在对应的 AI 回复内。
- 预览窗口支持独立置顶，切换对话后继续生效。

## English

- Chat preview reads the selected conversation in full and lists each question in a collapsible outline. Long prompts wrap in full. New messages preserve expanded questions and the reading position.
- In an expanded message, images appear in upload order before the user's text. Click an image to enlarge it or a file attachment to open it. Tool activity appears inside the corresponding AI reply.
- The preview window has its own always-on-top pin that stays active when switching chats.
