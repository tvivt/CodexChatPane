# v0.6.4

## 中文

- 修复新版 Codex 的项目归属、未读、对话/项目置顶和项目顺序同步。优先读取当前全局 SQLite，兼容旧 JSON；空集合会覆盖旧记录。归属只采用显式记录，不再通过工作目录或项目根目录推断。
- 重命名后同时观察线程库与标题索引，支持任一来源先更新，无须发送消息；后续刷新不会用未变化的旧值撤销已观察到的新标题。
- 修复全局库 WAL 通知可能早于提交可见导致漏刷的问题，按事件有限复查；无关设置写入不会触发目录扫描。
- 修正历史用量缓存的项目分组，只更新目录元数据，不重新解析请求日志。目录快照缺失、过期或来源不同时保留已知归属。
- 首次 MCP 告知弹窗首行以加粗警示色说明程序图标仅在系统托盘显示，不在任务栏显示。
- 包含此前未单独发布的 [v0.6.2](v0.6.2.md) 与 [v0.6.3](v0.6.3.md)：更新型号价表和待答问题刷新；完整对话预览、大纲、图片、附件、工具记录及独立置顶。

## English

- Fixed project assignments, unread state, chat/project pins and project order with newer Codex versions. Current global SQLite settings take precedence over legacy JSON, including empty sets. Membership uses explicit assignments only; working directories and project roots no longer imply membership.
- Renamed chats observe both the thread database and title index, regardless of which updates first, without requiring a new message. Unchanged stale values do not undo an observed rename.
- Fixed missed updates when a global-state WAL notification arrives before its commit is visible. Bounded rereads follow file events; unrelated settings writes do not trigger catalog scans.
- Corrected historical usage project groups by updating catalog metadata without reparsing request logs. Missing, stale or foreign catalogs preserve known cached assignments.
- The initial MCP consent dialog starts with a bold, highlighted notice that the app icon appears only in the system tray, not on the taskbar.
- Includes the previously unpublished [v0.6.2](v0.6.2.md) and [v0.6.3](v0.6.3.md) changes: updated model pricing and pending-question refresh, plus full conversation previews with an outline, images, attachments, tool activity and an independent always-on-top pin.
