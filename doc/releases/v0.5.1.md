# v0.5.1

2026-10-29 · Windows portable release

## 中文

- 主界面仅显示 Projects，隐藏 Projects/Chats 标签；独立 Chats 页代码保留。标题栏 CodexChatPane 加粗，旁边显示实际包版本。
- 额度百分比后显示可用重置卡数量；最近可用卡 7 天内到期显示 ⚠，3 天内显示 ❗。竖线、数量与额度百分比使用相同文字颜色，提示标识紧接数量。
- 额度区域统一悬停提示，显示额度重置时间、重置卡数量与各批到期时间；未知数量显示 `—`，不会当作 0。
- 修复归档操作成功后仍长时间处理中：状态回读改为目录元数据查询，避免重复解析全部对话日志。
- 普通对话移除标题前的会话图标及占位，通过右键菜单归档；归档对话保留恢复图标。归档和恢复均直接执行，不再二次确认。
- 同步中英文首页、使用说明和产品文档。GitHub Release 正文直接使用本文件。

## English

- Show only the Projects view, hide the Projects/Chats tabs, and retain the standalone Chats implementation. Display a bold app name and the package version in the titlebar.
- Append the available reset-card count to quota percentages. Show ⚠ for an available card expiring within seven days and ❗ within three days, directly beside the count. Match the separator and count to the percentage text color.
- Use one quota tooltip for quota deadlines, reset-card counts and expiry batches. Unknown counts display `—`.
- Fix prolonged archive processing after a successful operation: verify catalog metadata without reparsing all conversation logs.
- Remove the leading icon and its space from active chats; archive through the context menu. Retain the restore icon for archived chats. Neither action asks for another confirmation.
- Update both language guides and publish this file as the GitHub Release body.
