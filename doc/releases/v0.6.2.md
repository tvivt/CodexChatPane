# v0.6.2

## 中文

- 提交问题卡片的回答后，侧栏会根据会话日志或历史数据库通知清除 `?`，并显示对话当前的工作状态。侧栏可见且仍有待答问题时，每 5 秒补查一次。最后一个问题答完或窗口隐藏时停止补查，恢复可见时立即核对。
- 更新 API 等价金额价表，补全 GPT-6.2 Astra、GPT-6.2 Sol 和 GPT-6.1 Terra 等型号及其服务档位。已有历史报告会在下次打开时按更新后的价格重算。[计价说明](../usage-history.zh-CN.md)

## English

- After you answer a question card, the sidebar uses changes to the conversation log or history database to clear `?` and show the current chat status. A visible window checks outstanding questions every five seconds as a fallback. The checks stop when the last question is answered or the window is hidden. Showing the window checks for answers immediately.
- Updated API cost estimates for GPT-6.2 Astra, GPT-6.2 Sol, GPT-6.1 Terra and their service tiers. Existing usage reports recalculate with the updated prices the next time you open them.
