# v0.5.7

## 中文

- 动态栏增加四种状态多选，默认全选。ALL 随单项选择显示全选、半选或全不选，点击全选态清空，其余情况全选。计数保留零值，按当前天数、手动覆盖、项目筛选和标题搜索统计；对话状态变化实时更新列表。
- 动态栏支持独立按对话标题搜索。工具排列为 Days、N、P 与项目排序和漏斗、五个状态，以及右侧搜索等工具。P 开启时下划线贯穿三个项目控件，各自可点击；有项目筛选时显示实心漏斗。隐藏项目列保留排序和筛选。
- 动态栏和 Projects／Chats 的 N 共用三态箭头，默认并排上／下箭头，升降序分别显示单箭头。未启用的普通控件为灰色，启用时加色彩和下划线；五个状态图标保留各自配色，待查看为红色，待回答为加粗琥珀问号。
- 动态栏保持单行，左右工具分组对齐。窄栏先收纳右侧工具至“更多”，保留五个状态控件；搜索及右侧工具组前保留分隔线。统一按钮高度、图标中心和计数对齐。
- 开启文件夹联动时立即定位当前选中对话的项目和会话文件夹。
- Projects 项目行去掉竖线前的状态占位，保留多选框与项目名后的状态、计数；三种状态标签统一高度和图标槽，工作动画期间计数位置稳定。
- 底部对话时间保留今天／昨天，本年其他日期省略年份，跨年保留年份；时间组左边距调整为 6px。

## English

- Recent activity supports multiple status selections, initially including all four states. ALL reflects full, partial or empty selection; clicking it clears a full selection or selects all otherwise. Counts include zeros and reflect the day range, manual overrides, project filter and title search. Chat status changes update the results.
- Search recent chat titles independently. The toolbar places Days, N, P with project sorting and filtering, five status controls, then search and other tools. Enabling P underlines the project group; its controls remain independently clickable. A solid funnel indicates filtering. Hiding the project column preserves sorting and filters.
- Recent N, Projects/Chats N and recent project sorting share default double arrows and single ascending/descending arrows. Inactive ordinary controls are gray; active controls use color and underlines. Status icons keep their colors, including a red unread dot and a heavier amber question mark.
- The toolbar stays on one line, with left and right groups aligned. Narrow panes collect right-hand tools in More first, keeping all five status controls visible. A divider precedes the search/tools group. Button heights, icon centers and counts are aligned.
- Enabling folder linkage immediately reveals the selected chat's project and chat folder.
- Project rows omit the leading status placeholder, keeping selection checkboxes and status counts beside project names. Status badges have fixed heights and icon slots, with stable counts throughout the working animation.
- The selected chat's bottom-bar time keeps Today/Yesterday labels, omits the year for other dates in the current local year and retains it for other years. The time group starts at a 6px left margin.
