# v0.5.6

## 中文

- Projects 栏在 `N` 排序按钮右侧显示项目在树中的路径，例如 `工作 / 工具 / CodexChatPane`。路径使用随主题调整的绿色粗体字，字号比栏标题小 1px。
- 点击项目时，只展开所点位置的文件夹和上级目录，收起其他普通项目文件夹。同一项目出现在多个位置时，路径跟随点击的位置。
- Chats 栏只保留文件夹导航。点击树中的对话会展开它所在的路径，并收起当前项目的其他普通对话文件夹。两栏的 `PIN / STAR` 都是快捷入口，项目和对话保留在原文件夹，快捷入口的展开状态独立。

## English

- The Projects header shows the selected project's tree path beside the `N` sort button, for example `Work / Tools / CodexChatPane`. The path uses bold, theme-aware green text one pixel smaller than the header.
- Clicking a project opens its containing folder and ancestors and collapses other ordinary project folders. If the project appears in several folders, the path follows the occurrence you click.
- The Chats header omits the path text. Clicking a chat in the tree opens its folder and ancestors and collapses other ordinary chat folders in the current project. In both trees, `PIN / STAR` provides shortcuts, preserves the original folder membership, and keeps its own expanded or collapsed state.
