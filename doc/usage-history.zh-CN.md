## 入口与显示

状态栏额度可点击或用 Enter/空格打开独立的 `usage-history` 窗口。默认显示“消耗详情”，选择当前 W 周期；仅有历史 W 时选择最近周期，没有 W 记录时使用当前自然月。当前 W 周期在启动并确认账号后延迟预加载，其他历史范围按需建立索引。

消耗详情按“范围栏 → 横向筛选 → 概览 → 趋势 → 汇总表”排列。“重置周期”和“自然时间”互斥，各自保留选择，不取交集。重置周期仅统计 W，复选下拉框可选择所有已记录周期、当前周期或不连续的多个历史周期，点击“应用”后加载。自然时间用日/周/月/全部按钮，配合日期及前后切换；日以本地零点、周以周一零点、月以每月一日为界。只有自然时间“全部”不限制历史时间；“所有周期”仍限制在已记录 W 周期的并集。

项目、模型、来源（全部/主对话/子代理）与 Fast 用横向按钮切换，同类单选、跨类组合。概览显示 API 等价金额、输入/输出、缓存命中率及请求/对话数，趋势和汇总使用相同条件。短范围按小时、长范围按日展示；长历史最多合并为 60 个图形分桶，未选择周期的空档与零消耗区分。

默认按项目、按金额倒序，可按列排序或用按钮切换日期、模型汇总。额度窗口不再展示对话列表或逐请求展开。单个对话的消耗放在既有“对话详情”：本对话全部已结算用量独立于计时范围显示，各轮次、各请求显示对应金额，子代理在各自一行显示独立金额。直接复用该次详情读取的逐请求数据和同一份价表，不额外索引其他对话。可靠用量即使缺少速度计时也可计价；进行中和中断轮次的已结算请求纳入，继承历史、其他 thread_id、重复和冲突请求排除。未计价的用量保留，不显示为免费。

“重置记录”仅按时间倒序展示当前 W 周期及已记录 W 重置，显示方式、结束情况和最后余额；展开查看周期覆盖、原定重置、耗尽时间和已观察消耗，可直接进入该周期的消费详情。未观察到是否耗尽时显示“记录不足”。顶部显示重置卡数量，展开显示到期时间，复用最近一次额度快照。状态栏的即时额度展示保持原样。

额度 tips 显示 `rateLimitResetCredits.availableCount` 和明细到期时间，按到期时间排序。明细缺失时数量仍以服务端总数为准。到期时间格式为 `2026-10-30 00:00 (-6d5h)`，超过 24 小时使用天和整小时。

提前重置通知保留到手动关闭，关闭状态持久化。同一事件不会在重启后反复通知。显示名称为自然重置、重置卡、提前重置，不显示“推测”“已确认”“来源未知”后缀；没有精确时间时显示前后采样区间。

## 额度周期

`usage/ledger.rs` 接收现有外部 MCP / app-server 的额度查询结果。只读额度查询不兑换重置卡。记录按账号隔离；没有账号 ID 的快照使用独立的未知账号分区，不能与已知账号合并。套餐变化单独断开周期。

- 自然重置：前次预定重置时间处于两次观察之间，且窗口截止时间改变。
- 重置卡：同一张卡从 available 明确变为 consumed/redeemed。只减少数量或卡从列表消失不能证明兑换，过期也不能算重置。
- 提前重置：原定重置时间之前观察到额度恢复及窗口变化，缺少兑换证据。
- 周期以重置为边界。耗尽时记录时间，等待下一次重置后才结束周期；未耗尽即重置的事件同样保留，记录重置前最后余额。没有观察到耗尽时，“是否用完未知”，不把最后一次非零余额当作临界时刻证据。
- 只累加同一周期内正向的已使用百分比变化，单位为百分点。采样间的消费可能遗漏，因此称“已观察消耗”，不反推每个对话的额度。
- 首个周期起点未知，标记不完整。跨度超过整个额度窗口的缺口不补造中间周期。5h/W 两套周期独立，不能相加。

账户额度历史从开始记录时起积累。当前接口不是历史账单，无法补齐此前的重置记录。对话日志属于本机可读取的会话，不能据此声称覆盖云端、其他设备或其他使用同一额度的产品。

## 消耗与计价

`usage/costs.rs` 复用 `metrics::read_own`，仅解析自己的逐请求用量，不收集消息正文和活动内容。包含当前及中断轮次中已结算的请求；计时字段缺失不影响可靠 token 的统计。重复、冲突或非法用量不重复计入；继承历史按目标 thread_id 排除。

主对话与子代理费用分列，父子链归入同一对话与项目，各请求仅统计一次。以用量结算时间分日，跨天/跨周期对话按请求拆分；没有结算时间的请求保留在全部范围的“未分配”中，不按创建时间回填。项目归属使用当前主窗口目录映射；不是历史项目归属快照。已缓存的消费可在原始日志不可用时保留，读取错误在覆盖说明中显示。

API token 等价金额使用 `usage/pricing.rs` 的 USD/百万 token 价表，价表日期固定记录为 2026-10-23，来源为 <https://developers.openai.com/api/docs/pricing>。历史消耗按这一版公开 API 价格重新估值，不代表当时账单或订阅扣款。

- 分别计算未缓存输入、缓存读取和输出；推理已包含在输出内，不重复计费。
- Fast/priority 使用对应价格；长上下文按每次请求输入是否超过 272K 判定。
- 未记录档位时按 Standard 估算；缺少缓存写入量按普通输入，有写入量但没有 TTL 时按 30m 价格估算，并统计计价信息不完整的请求数。
- 模型或档位无匹配价格时显示未计价，不套其他模型价格；汇总只累加已知部分并提示未计价请求数。
- 不包括工具调用、图片、音频等独立费用，也不将额度百分比换算为固定金额。

## 存储与性能

额度快照和关闭标记保存在 `CODEX_HOME/.codex-chat-pane/usage.sqlite`。消耗逐请求明细和汇总结果保存在同目录的 `usage-cache-<身份摘要>.sqlite`，均为可跨启动复用的本地文件。不保存提示词、回复正文或登录令牌。

快照相同时合并观察时间。日常复用现有可见窗口每分钟额度查询，不为此增加全会话轮询。打开重置记录不读取全部对话。默认只索引当前周期；没有周期记录时加载当前自然月。切换上一周期或上个月才加载相应时间段，只有选择自然时间“全部”才索引全量。候选对话按创建/更新时间与所选范围的交集筛选；长对话或单个压缩文件首次仍可能需要顺序解码。之后只重读变化的依赖日志，按实际文件路径/长度/mtime 检测 jsonl、jsonl.zst 替换和续接。索引串行执行并显示进度，已覆盖范围内的汇总分组与筛选只查询缓存。现有状态栏速度仍只读取当前选中对话的最新请求。

启动目录快照及首次在线额度查询都完成后，延迟 3 秒预加载当前已观察的 W 周期；5h 重置不会触发 W 缓存重载。周期起点未知时使用首个观察时间，不猜测完整周期。后续按结算修订标识定向更新变化的对话；未出现在主目录中的子代理或续接文件由文件监听补充。预加载串行执行，期间的新结算保留到下一批。切换周期、账号或来源后重新检查当前范围，不自动加载所有历史。

多选周期先合并相邻或重叠边界，每个未覆盖区间单独建立索引；不把最早到最晚之间的未选周期作为读取范围。最终汇总按区间并集过滤，每个请求只统计一次。已覆盖区间直接查本地缓存，快速筛选复用同一范围内正在进行的索引；账号切换清空范围提示和正在复用的任务引用，旧结果不能回到新账号页面。

状态栏和详情已解析的逐请求用量会直接合并到消耗明细，响应 ID 去重；部分读取不能把整份日志标记为已索引。完整索引只更新变化的请求及删除已不存在的请求。汇总按查询范围、分组、时区和价表日期持久化；按请求所在 UTC 日的修订号失效，无关日期的新消耗不会重算历史汇总。标题、项目归属、父子关系或覆盖错误变化时，汇总保守失效。损坏的汇总 JSON 会重算，原始日志变化时仍需检查和解析相应对话。

缓存身份包括 Windows MachineGuid、规范化 Codex 数据目录、状态数据库创建标识及服务端确认的账号 ID，解析格式版本也参与身份。换机器、数据目录、账号或替换状态库后使用独立缓存文件，原文件保留。每次启动必须先获取当前账号；不依据磁盘中的上次账号直接复用。账号未知、退出登录或 `auth.json` 发生变化时暂停复用，直到重新确认。账号切换会清空打开的详情筛选与旧结果，正在执行的旧账号任务不返回新账号页面。

日志未提供可靠的逐请求账号归属，切换账号不会把本机历史自动变成该账号账单；隔离的是缓存上下文，重新读取的仍是当前数据目录可见的本地日志。API 金额始终是本地会话估算。

- `cargo test --manifest-path src-tauri/Cargo.toml --lib usage::`：自然/提前重置、耗尽记录、卡过期不误判、快照合并、关闭持久化、计价、子代理去重、压缩日志替换和继承排除。
